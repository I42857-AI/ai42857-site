## 1. 产品概述

个人作品集网站 `ai42857.dpdns.org`，展示创作者在 AI Agent 生态、开发项目、视觉作品和写作四个维度的成果。
- 目标：让访客在 10 秒内理解「这个人做什么」，3 分钟内深入感兴趣的领域
- 价值：不是简历，是活的作品橱窗——每个项目可交互、可体验

## 2. 核心功能

### 2.1 页面结构
1. **首页**：英雄区 + 四维导航 + 精选作品轮播
2. **Agent 生态页**：TRAE/MiMo 双 Agent 架构、技能体系、虫洞链接可视化
3. **开发项目页**：项目卡片网格 + 技术栈标签 + GitHub 链接
4. **视觉作品页**：视频/分镜/设计作品画廊
5. **写作页**：文章列表 + 标签筛选

### 2.2 页面详情

| 页面 | 模块 | 功能描述 |
|------|------|---------|
| 首页 | 英雄区 | 个人标识 + 一句话定位 + 粒子/虫洞动效背景 |
| 首页 | 四维导航 | Agent/开发/视觉/写作 四个入口卡片，悬停展开预览 |
| 首页 | 精选轮播 | 自动轮播 3-5 个代表作，含缩略图和简介 |
| Agent 生态 | 架构图 | TRAE + MiMo 双 Agent 协作关系可视化（交互式） |
| Agent 生态 | 技能清单 | 30+ 技能卡片，可筛选/搜索 |
| Agent 生态 | 虫洞演示 | Symlink 虫洞链接原理动画 |
| 开发项目 | 项目网格 | 响应式卡片布局，含技术栈标签和状态徽章 |

## 4. 用户界面设计

### 4.1 设计风格
- **色调**：深色系为主（#0a0a0a / #111111），暖铜色强调（#c45d2c），沙色辅助（#e8e0d4 / #8b7355）
- **字体**：展示字体用 Playfair Display（衬线，个性），正文用 Noto Sans SC（中文优先）
- **布局**：非对称网格，大量留白，卡片式内容组织
- **动效**：虫洞粒子背景 + 滚动视差 + 悬停微交互 + 页面切换过渡
- **图标**：lucide-react 图标库

### 4.2 页面设计概览

| 页面 | 模块 | UI 元素 |
|------|------|---------|
| 首页 | 英雄区 | 全屏深色背景 + 粒子虫洞动效 + 大标题 + 副标题 |
| 首页 | 四维导航 | 2x2 网格卡片，悬停放大+发光边框 |
| 首页 | 精选轮播 | 水平滚动卡片，含缩略图+标题+标签 |
| Agent 生态 | 架构图 | 交互式节点图，可拖拽/缩放 |
| Agent 生态 | 技能清单 | 可筛选标签栏 + 技能卡片网格 |
| 开发项目 | 项目网格 | 响应式 masonry 布局 |
| 视觉作品 | 画廊 | 瀑布流 + 灯箱弹窗 |
| 写作 | 文章列表 | 时间线 + 卡片 |

### 4.3 响应式
- 桌面优先（1440px 基准）
- 平板适配（768px）：卡片从 3 列变 2 列
- 手机适配（375px）：单列布局，汉堡菜单

### 4.4 动效设计
- **虫洞粒子**：首页英雄区背景，粒子沿 Symlink 路径流动
- **滚动视差**：各区块滚动时背景和前景不同速度移动
- **悬停效果**：卡片悬停时微微上浮+阴影加深+边框发光
- **页面过渡**：路由切换时淡入淡出+轻微位移
